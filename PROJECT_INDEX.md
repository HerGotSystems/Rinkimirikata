# Rinkimirikata — Project Index

## Purpose

Rinkimirikata is the umbrella / portal layer for the user's public systems, engines, frameworks and experiments.

It should act as a top-level gateway that links people into the correct working engine instead of sending them to raw GitHub repositories or dead placeholders.

## Repo

HerGotSystems/Rinkimirikata

## Role In The System

Rinkimirikata is not one product. It is the public navigation layer for multiple products and concepts.

Important connected systems:

- HumanX
- Belief Engine
- Claim Engine
- Evidence Vault
- Truths
- EMVYCHECK / Nexus music platform direction
- Omniforge / System Forge

## Known Design Rule

Rinkimirikata should feel like a command portal, not a pile of project cards.

If a thing is working, route users to the working app.
If a thing is conceptual, label it as concept / coming soon.
If a thing is source-only, label it as GitHub/source.

## Current Problems / Next Work

- Some cards/buttons may still point to GitHub repos instead of live engines.
- HumanX should be represented as umbrella, not just Claim Engine.
- Nexus likely overlaps with the current EMVYCHECK music platform direction.
- Navigation should be reduced and clarified so users do not get dumped into code.

## Critical Instruction For Future AI Work

User does not code.

Prefer direct GitHub edits, full file replacements, or one exact copy-paste block.

Avoid telling the user to hunt for small syntax changes.
